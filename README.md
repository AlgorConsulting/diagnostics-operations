A representational sample built by ALGOR Consulting Group (https://www.algor-consulting.com/). All patient, test, turnaround, revenue and data-quality figures are synthetic and illustrative; no client data is used.

Tabs: Daily Report, Executive Summary, Turnaround (TAT), Data & Sample Quality, Patients & Channels. Filters: financial year (Apr-Mar), period, zone, centre, department, patient channel.
